# S BYTE — Customer Quick-Commerce Mobile Application

Customer-facing quick commerce and local marketplace mobile application for S Byte, launching in Nagercoil and Tirunelveli, built with React Native and Expo 52.

## Features
- **Multi-Shop Discovery**: Discover participating local supermarkets, compare prices, and view delivery estimates.
- **Express 15-Minute Delivery**: Ultra-fast grocery and supermarket delivery.
- **One-Shop Checkout Integrity**: Concurrency protection ensuring cart items originate from a single fulfillment branch.
- **Order Tracking & Notifications**: Live preparation, dispatch, and delivery timeline.
- **Loyalty Rewards & Coupons**: Tiered loyalty program and promo codes.

## Quick Start (Standalone)

```bash
# 1. Install dependencies
npm install

# 2. Start Expo Metro bundler
npm start

# 3. Open in browser or Expo Go
npm run web
# or scan QR code on Android/iOS via Expo Go
```
